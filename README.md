Extract ZIP
Download "https://github.com/GhostlyDark/retro/releases" (v0.0.5 or newer). This is a version of Retro with disabled compression to avoid stuttering issues.
Choose Create OTR -> Replace Textures -> Yes and select the folder containing HD textures.
It is recommended to prepend alt/ before staging textures. This allows assets to be toggled on-the-fly.
Finalize OTR as the final step.
